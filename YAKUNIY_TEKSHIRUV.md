# AgroPulse — yagona platforma yakuniy qabul ro‘yxati

## Kod bo‘yicha bajarilgan avtomatik tekshiruvlar
- TypeScript/TSX sintaksisi.
- Muhim fayllar, havolalar, rasm yo‘llari va birlashgan platforma tarkibi.
- ZIP yaxlitligi.

## Windows'da majburiy qolgan tekshiruvlar
- [ ] `BOSHLASH_WINDOWS.bat` bilan server ochiladi, `127.0.0.1:3000` ishlaydi.
- [ ] `TEKSHIRISH_WINDOWS.bat` production build va turlarni xatosiz tekshiradi.
- [ ] Menyuda faqat bitta `Platforma` yo‘nalishi bor, uning ichida 4 rol va 5 tab ishlaydi.
- [ ] Eski `/platform`, `/suv-platformasi`, `/dashboard` manzillari `/#platforma`ga qaytadi.
- [ ] Dastlabki bosh sahifa fonlari va interaktiv bo‘limlar buzilmagan.
- [ ] UZ / RU / EN tanlash ochilib-yopiladi, boshqa tabga o‘tganda ham saqlanadi.
- [ ] Fermer, Irrigatsiya, Hokimiyat, Administrator rollari bir-birining interfeysini demo sifatida almashtiradi.
- [ ] Xarita nuqtalari tanlanadi; Sarf grafigida davr almashadi; Ogohlantirishlar kengayadi.
- [ ] Telefon (360px), planshet (768px), desktop (1440px) ekranlarda gorizontal scroll va ustma-ust chiqadigan blok yo‘q.
- [ ] Klaviaturada navigatsiya va `prefers-reduced-motion` tekshirildi.
- [ ] Haqiqiy kompaniya kontaktlari, real prototip materiallari va tasdiqlanmagan da'volar ish egasi bilan ko‘rib chiqildi.

**Haqiqiy API ulanishi va jonli sensor sinovlari bu frontend ishining tashqarisida.**
